# 🌈 BrightSteps — Learning Hub for Kids (Ages 6–8)

A calm, distraction-free, interactive learning web app tailored for children aged 6–8 with learning differences (Dyslexia, Dyscalculia, ADHD, and Autism / Executive Function support).

## ✨ Included Activities & Features

1. **🔤 Reading & Phonics (Dyslexia Support)**
   - **Word Builder**: Color-coded phonics tiles (Orange = Vowels, Blue = Consonants), visual emoji cues, read-aloud audio (`🔊`), and zero-penalty hints.
   - **b / d / p / q Letter Detective**: Helps children overcome common letter reversals with visual memory tricks.
2. **🧮 Visual Ten-Frame Math (Dyscalculia Support)**
   - **Visual Addition**: Pairs abstract equations with a tactile 10-frame manipulative where every dot can be tapped and counted aloud.
   - **Fill the 10-Frame**: Interactive counting box where kids place apples into a 10-frame to build number sense.
3. **🧩 Focus & Working Memory (ADHD Support)**
   - **Picture Match**: Bite-sized 8-card memory match with spoken word reinforcement.
   - **Sound & Color Pattern**: Gentle 3-step visual/audio sequence game to exercise working memory.
4. **🌟 My Daily Routine & Feelings Check-In (Autism / Executive Function Support)**
   - **Step-by-Step Visual Schedule**: Interactive checklist with progress bar and star rewards.
   - **Feelings Check-In & Calm Breathing Bubble**: Helps children identify emotions and practice guided 4-second belly breaths.
5. **🏆 Star Jar, Sticker Book & ⚙️ Parent Dashboard**
   - Kids earn stars (`⭐`) for every completed activity to unlock 10 collectible stickers.
   - Parents can personalize their child's name, add custom school spelling words, customize daily routine steps, and view progress—all saved automatically in the browser (`localStorage`).

## 🚀 How to Host This App for Free (Step-by-Step)

Because BrightSteps is built with pure HTML, CSS, and JavaScript (`index.html`, `styles.css`, `app.js`), it requires **zero paid servers or databases** and can be hosted 100% for free in under 2 minutes!

### Option 1: Netlify Drop (Easiest — Drag & Drop, No Coding Required)
1. Go to **[https://app.netlify.com/drop](https://app.netlify.com/drop)** in your web browser.
2. Sign up for a free Netlify account (using Email or Google).
3. Open your computer's File Explorer and locate the folder:
   `C:\Users\User\.gemini\antigravity\scratch\bright-steps`
4. **Drag and drop** the entire `bright-steps` folder onto the dashed box on the Netlify Drop page.
5. Within 5 seconds, Netlify will give you a live public link (like `https://bright-steps-12345.netlify.app`) that you can open on any iPad, tablet, phone, or computer!
6. *(Optional)* In Netlify's **Site Configuration -> Change site name**, you can rename it to something easy to remember like `my-kid-brightsteps.netlify.app`.

### Option 2: GitHub Pages (100% Free Forever)
1. Create a free account at **[https://github.com](https://github.com)**.
2. Click the **+** icon in the top-right corner and select **New repository**.
3. Name the repository `bright-steps`, make sure it is set to **Public**, and click **Create repository**.
4. Click the link that says **"uploading an existing file"**.
5. Drag `index.html`, `styles.css`, and `app.js` from `C:\Users\User\.gemini\antigravity\scratch\bright-steps` into the upload box, then click **Commit changes**.
6. Go to the repository's **Settings** tab -> click **Pages** on the left sidebar -> under **Branch**, change `None` to `main` and click **Save**.
7. Wait about 60 seconds, and your site will be live at `https://<your-username>.github.io/bright-steps/`!

### Option 3: Tiiny.host or Surge.sh (Quick Testing)
- **Tiiny.host**: Zip the `bright-steps` folder into `bright-steps.zip`, go to [https://tiiny.host](https://tiiny.host), and upload the zip file for an instant preview link.
